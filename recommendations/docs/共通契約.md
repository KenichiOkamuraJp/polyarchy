## 1. 受け取るもの（共通部との差分のみ＝一覧と作法は [polyarchy_common/README.md](../../polyarchy_common/README.md)）

## 2. 約束するもの（入口の作法＝共通契約 §2 を全て適用）

共通部 §2 の作法は全て適用（本書には写さない）。出典の形＝団体・文書名・発行日・doc_type・分野タグ・ページ・原文 URL。
recommendations 固有の約束：

- **生成・要約はしない**（返すのは関連度順のチャンク＝本文抜粋と出典メタのみ。文章化は利用者側）。
- **文書全文は返さない**（抜粋単位＝再配布条件の軽微性の枠。契約値は [再配布条件.md](再配布条件.md) が正典）。
- 収録範囲の負のスコープ宣言・団体別鮮度・低ヒット警告を応答に含める（[コーパス収録範囲の明示.md](コーパス収録範囲の明示.md)）。

## 3. 名前

- フォルダ名＝`recommendations`／データ刻印・コレクション接頭辞＝`policy_claims`（§1 のとおり据え置き）。
- systemd `polyarchy-mcp.service`（歴史的に mcp の名のまま＝内部配線名は改名対象外・2026-08-27 決定）。
- 公開ホスト名 **`recommendations.<domain>`**（2026-09-02 ドメイン移行で確定＝「mcp.」というホスト名は廃止）。
- MCP サーバ名 `polyarchy-policy-search`（`serving/mcp_server.py` の `SERVER_NAME`）。
- 公開ツール 3 本＝`search_policy_docs`（単発）・`sweep_policy_docs`（団体横断の多段）・`list_orgs`（団体・鮮度）。

## 5. 契約値（数値・変えるときは根拠文書と同時に）

| 値 | 現行 | 根拠・正典 |
|---|---|---|
| `top_k` | 既定 5・**上限 20**（`TOP_K_MAX`。超過指定は 20 にクランプし `applied_filter` で開示） | 応答肥大の歯止め（20 件×本文 ≒24k 字。経緯＝残タスク §E-A2） |
| sweep の結果上限 | **15 件**（per_org 既定 3・**上限 5**・全 5 団体走査） | 多段設計（詳細＝残タスク §E-A2） |
| 重複抑制（diversify） | **本番経路（MCP・eval）は on**＝文書単位（同一文書は最良チャンク 1 件・`applied_filter` で開示）。★`PolicySearchService` 自体の既定は **off**＝on は各呼び出し側が明示（新しい呼び出し元を作るときは `diversify=True` を明示すること） | バッチ2 段1 で本番経路に一本化＝eval アンカーも同経路（根拠の詳細＝残タスク §E-A2） |
| 検索品質アンカー | hit@5／MRR ほか | **ルート [README](../../README.md)「品質の担保」が正典**（本書には写さない） |
