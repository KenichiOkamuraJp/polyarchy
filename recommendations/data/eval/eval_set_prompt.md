# RAG評価セット作成依頼（Cowork向け）

> **状態：記録（初期の評価セットを作ったときの依頼文・更新しない）。**

## 0. 背景

政策文書を対象とするRAG（検索拡張生成）システムを構築している。
このRAGの精度を**客観的に測るための評価セット**を作りたい。

評価セットは「質問 → 期待されるキーワード／参照PDF」のJSONリスト。
これがあれば、後続フェーズで「チャンクサイズを変えたら精度上がるか」「埋め込みモデルを変えたら？」といった条件比較を**数字で**評価できるようになる。

## 1. お願いしたいこと

添付した5本のPDFを読み込み、評価用のQ&Aペアを **合計20〜30問** 作成してください。

### 1.1 対象PDF（5本）

| ファイル名 | 概要（既知） |
|---|---|
| `016.pdf` | HR部門におけるAI等の活用に関する報告書（経団連、2026年4月） |
| `018_honbun.pdf` | 税・財政・社会保障一体改革に関する基本的考え方（経団連、2026年4月） |
| `019_honbun.pdf` | スタートアップ育成5か年計画の先を見据えた基本戦略（経団連、2026年4月） |
| `020.pdf` | 物流に関する公正取引委員会告示案へのパブリックコメント意見（経団連、2026年4月） |
| `087_honbun.pdf` | カーボンニュートラル／業界別CO₂排出量データを含む大部の報告書 |

### 1.2 出力形式

以下のJSONを `eval_set.json` という1ファイルにまとめて出力してください。

```json
[
  {
    "id": "001",
    "question": "自然な日本語の質問文",
    "expected_keywords": ["キーワード1", "キーワード2", "キーワード3"],
    "expected_source": "016.pdf"
  }
]
```

- `id`：通し番号（"001", "002", ...）
- `question`：自然な日本語の質問文（口語的でよい。実際にユーザーが投げそうな問）
- `expected_keywords`：その質問への正答に**必ず含まれているべき語**を3〜4個。固有名詞・概念語・数字など。曖昧な語は避ける
- `expected_source`：その質問の根拠が記されているPDFのファイル名（**1ファイルに絞る**。複数文書をまたぐ問は今回は作らない）。文書外の質問の場合は `null`

### 1.3 数量と配分

- **各PDFから4〜5問**ずつ → 約20〜25問
- 加えて、**「意地悪枠」として文書に書かれていないことを尋ねる問を3問**程度作る（`expected_source: null`）
  - 例：「経団連は海外進出戦略についてどう述べているか？」（5本のPDFには書かれていない）
  - これらはRAGが「文書からは確認できません」と返せるかを試す問

合計 **23〜28問** を目安にしてください。

### 1.4 質問のバリエーション

各PDFについて、以下の **異なるタイプの問を混ぜる** ようお願いします：

1. **概要把握**（"〜について何が書かれているか？" / "本提言の主旨は？"）
2. **具体的事実の確認**（"〜社のCO₂削減率は？" / "AIを採用に活用している企業数は？"）
3. **スタンス・主張の確認**（"〜について経団連はどう考えているか？" / "〜に賛成か反対か？"）
4. **数値・統計**（"アンケート対象企業数は？" / "削減目標年は？"）
5. **理由・前提条件**（"なぜ〜と主張しているか？" / "〜の前提条件は？"）

特定タイプに偏らないようにしてください。

### 1.5 質問の品質基準

- **答えがPDFに明確に書かれている**ものだけ採用（推測が必要なものは作らない）
- **複数の解釈ができる曖昧な問は避ける**
- **「Yes/No」だけで終わる問は1〜2問にとどめる**（理由・条件まで含めて答えさせる問の方が評価で効く）
- **問の長さは20〜80文字程度**

## 2. 作業手順の提案

1. まず5本のPDFをすべて通読
2. 各PDFごとに、上記5タイプを意識しつつ4〜5問の素案を作る
3. 「意地悪枠」3問を追加
4. 全体を見直し、重複・冗長な問を整理
5. 最終的な `eval_set.json` を出力

## 3. 注意事項

- **ファイル名は正確に**書いてください（例：`018_honbun.pdf` の `_honbun` を落とさない）
- **expected_keywords は実際にPDF本文に出てくる語**を選んでください（自分で言い換えた語ではなく）
- 出力は**JSONのみ**で結構です。コメント文や前置きは不要です

よろしくお願いします。
