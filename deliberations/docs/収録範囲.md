## 2. 入っていないもの

| 入っていないもの | 理由・どこにあるか |
|---|---|
| 会議の**決定文書**（取りまとめ・基本方針・基本計画・重点計画） | 政策主張DB の `gov`（`search_policy_docs`）。同じ会議体でも、決まった内容は政策主張DB、決まるまでの資料と議論は本DB（[開発計画](../../docs/審議会議事録DB_開発計画.md) §1・§9） |
| 上の 4 つ以外の会議体 | 第 2 便（規制改革推進会議 デジタル・ＡＩ WG・データ利活用制度・システム検討会・AI 制度研究会）・第 3 便（規制改革の旧デジタル系 WG と本会議・デジタル行財政改革の配下の残り・AI・デジタル改革推進会議）は計画のみ。人工知能戦略推進会議（持ち回り 2 回）も未収録 |
| 見送りの会議体 | 課題発掘対話・政策改善対話・共通基盤の連絡協議会・各府省庁 DX 推進連絡会議（主題が実務の進捗報告＝開発計画 §3.2） |
| 非公開の資料の本文 | 会議の一覧に名前だけ。公開層に固定（非公開の資料を扱う経路が無い） |
| 図・画像の中の文字 | 文字のレイヤーだけを読む（束ねた構成員提出資料で、提出者の表示が画像の中にあるページは提出者が不明になる） |
| 発言者・提出者の推定 | 記録・資料に書かれた文字列からだけ。匿名の要約の発言は「不明」。提出者の記載が無い資料は会議資料の慣行により事務局（`presenter_basis＝既定` で区別） |

## 3. 鮮度

収集（`python -m deliberations.ingest.collect`）は会議体の一覧ページから回を見つける＝新しい回が一覧に載れば次の収集で入る。箱での定期的な更新は箱へ置いた後（M6）に決める。2026-10-04 時点の最新は人工知能戦略本部 第 5 回（2026-07-10）。AI・デジタル改革推進会議（デジタル行財政改革会議の後継）は掲載先も初回の開催も確認できていない。
