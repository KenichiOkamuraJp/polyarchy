## 2. 判定（文書の区分ごと）

| 区分 | 該当（第 1 便） | `license` | 扱い |
|---|---|---|---|
| 政府が作成した資料＝提出者区分が政務・事務局・府省・会議体 | 資料・参考資料 302 文書 | `PDL1.0` | 出典を示せば商用可。抜粋で返す（§3） |
| 記録＝議事録・議事要旨・議事概要 | 57 文書（発言の単位 3,065） | `PDL1.0` | 政府が作成・公開する記録。発言の内容は発言者のものであり、返り値で発言者と区分を必ず示す。会議の場の発言でなく書面で提出された発言要旨は `mode=written` で区別 |
| 第三者の著作物＝提出者区分が構成員（政府外）・外部（ヒアリング）の資料 | 165 文書（単位 1,457） | `第三者の著作物` | **PDL1.0 の対象外として扱う**。政策主張DB の経済団体の文書と同じ枠＝所在検索に伴う軽微な抜粋＋出典・原文 URL（§3・§4） |

- 区分は帰属の判定（[開発計画](../../docs/審議会議事録DB_開発計画.md) §4.1）の提出者区分から機械で決まる（`deliberations/ingest/build.py` の `license_of`）。束ねた構成員提出資料（ページごとに提出者が違う）は文書全体を第三者の著作物とする。
- 提出者の記載が無い資料は既定で事務局（政府）＝PDL1.0。内容が第三者の著作物を含む（他の機関の図表の転載など）可能性は残る＝原典の権利表記に従うよう返り値の出典で原文へ誘導する。
- 数は 2026-10-07 の取り込み（524 文書・12,236 単位）の実測。日本成長戦略会議では、会議に招いた企業・団体の資料（「…様提出資料」）も外部（ヒアリング）＝第三者の著作物。規制改革推進会議の WG は企業・団体のヒアリングが中心＝第三者の著作物が 37 文書（同じ資料から 1 応答 2 件までの絞りが効く）。自治体（八王子市など）の提出資料も、その会議で構成員でない出席者の資料＝外部（ヒアリング）として第三者の著作物に入れる。

## 3. 返す形（実装の契約値＝軽微な利用に留める設計）

| 契約値 | 実装 | 意味 |
|---|---|---|
| 本文は**抜粋のみ・1 単位 800 字まで** | `core/search.py` `Hit.to_dict(text_chars=800)`（超えたら「…」で切断を明示）。単位自体も取り込みで 600 字程度に分割済み（スライドは 1 ページ・長いページは分割・発言は 1 発言） | 全文を返さない |
| 1 応答の件数に上限（既定 5・上限 20） | `serving/mcp_server.py`（`TOP_K_MAX=20` へ丸める） | — |
| **第三者の著作物は同じ文書から 2 件まで** | `core/config.py` `PER_THIRD_DOC=2`（1 応答の中で） | 1 つの提出資料からの取得量を絞る。政府の資料と記録には掛けない（記録は 1 文書に多数の発言者がいる＝一律に絞ると正しい発言が落ちる・M5 で測定） |
| ページング・オフセットの引数なし | `search_deliberations(query, orgs?, since?, until?, doc_kinds?, roles?, top_k?)` のみ | n 件目以降を順にたどって全文を復元することができない |
| **全件に出典・原文 URL・利用条件** | 各ヒットに会議体・回次・開催日・資料番号・提出者／発言者と区分・`source_url`（スライドは `#page=`）・`license` | 原典へ誘導する性格。利用側の引用（出所明示）を機械的に支える |
| 第三者の著作物には注記 | `notes` に「提出者が権利を持つ資料＝所在の案内のための抜粋」 | 利用側に全文の利用は原典の条件に従うことを示す |
| 公開層のみ・fail-closed | 層は公開固定（ツールに layer 引数なし・共有ライブラリが layer の無い検索を拒む） | 非公開の資料は構造的に返らない（非公開の資料は一覧に名前だけ） |

`list_meeting` は資料の名前・提出者・原文 URL の一覧だけを返す（本文を返さない）。

## 4. 法的根拠（政策主張DB の整理の延長）

1. **収集・索引化（内部複製）＝著作権法 30 条の 4・47 条の 5 第 2 項**（情報解析と、所在検索サービスの準備のための収集・記録）。
2. **検索結果の抜粋提供＝47 条の 5 第 1 項 1 号**（所在検索サービスに付随する軽微な利用）。§3 の契約値が軽微性を担保する設計。政令の基準（漏えい防止・法解釈の確認体制・問い合わせ窓口・収集拒否措置の尊重）は政策主張DB と同じ運用で満たす。
3. **会議での公開の発言**：記録に載る発言は、国の機関で公開して行われた陳述にあたるものを含む（40 条）。ただし本サービスは記録（PDL1.0）として扱い、40 条だけに依らない。
4. **利用側の引用＝32 条・48 条**：全件に出典と原文 URL を返すため、利用側は出所を明示した引用ができる。
5. **帰属・同一性**：抜粋は原文のまま（要約・改変して発言者や提出者の見解として示さない）。民間議員・有識者・外部の資料を政府の立場として読ませない（返り値の区分と注記）。

## 5. 収集の作法

curl の UA・1 リクエストごとに 1 秒以上・robots.txt を尊重（cas.go.jp・cao.go.jp とも置かれていない＝2026-10-03・cao.go.jp は 2026-10-06 にも確認。digital.go.jp は置かれており、会議・資料のパス〔/councils/・/assets/〕は禁じていない＝2026-10-06）・JS チャレンジ／ログイン／レート制限は突破しない。**例外＝cas.go.jp は curl の UA に 404**（UA の文字列で弾く型）＝ブラウザの UA で取得（開発計画 §7）。
