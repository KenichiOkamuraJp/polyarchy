companies — 企業情報DB（Polyarchy）

更新日：2026-09-23

日本の有価証券報告書（EDINET・金融庁）に書かれた企業の数値を、公表どおりの値・出典つきで Claude から参照するためのリモート MCP サーバです。 「主張（政策提言）↔ 事実」の突き合わせの企業側の事実として作られており、該当する開示がなければ「ない」と返します（別の連結／単体の別・隣の項目・近い決算期の値で埋めません）。

出典：EDINET（金融庁）の有価証券報告書。本サービスは XBRL から値を抽出・加工して提供しています（公共データ利用規約 第 1.0 版）。値は各提出会社の開示に帰属し、本サービスは値を保証しません（原典で確認してください）。

接続

  1. claude.ai → Customize → Connectors → Add custom connector。名前 Polyarchy companies、URL は利用者ごとに個別にご案内します（当面は招待制。利用希望は下記連絡先へ）。
  2. 「Connect」→ ブラウザで開くログイン画面でサインイン。許可された利用者のみ接続できます。
  3. Claude Code：claude mcp add --transport http polyarchy-companies <URL>。

ツール（すべて読み取り専用）

ツール何をするか何を返さないか
find_company社名（一部・旧社名・英文社名でも可）・証券コード・EDINET コードから提出会社を同定候補が複数あるときは 1 社に決めず、候補の一覧を返します
lookup_company_facts企業×項目×決算期（決算期末の YYYY-MM）の値を厳密参照。連結／単体の別・会計基準・要素・出典（書類管理番号・提出日・引用 1 行）つき該当がなければ found=false と理由。派生値（利益率・前年比 等）は計算しません
lookup_segments企業×決算期のセグメント別の値を表ごと返す（区分×項目。セグメント情報の注記・従業員の状況・設備投資・研究開発の欄）。区分は会社が定義したラベルのまま・区分の種類（報告セグメント／調整額／全社／合計 等）つき業種横断の区分や利益の物差しへの寄せ・区分の合計の計算。単一セグメント・記載の省略のときは found=false と会社の文 1 行。米国基準の会社はセグメント情報の注記が XBRL に無いため found=false
list_items項目の語彙（キー・日本語の呼び名・対応する標準タクソノミの要素）値

使ってみる（プロンプト例）

  1. 「日立製作所の売上収益と親会社株主に帰属する当期純利益を、直近 5 期分、出典つきで表にして」
  2. 「湖池屋の従業員数・平均年間給与・平均年齢・平均勤続年数の推移は？」
  3. 「三菱ＵＦＪフィナンシャル・グループの売上高は？」（→ 銀行は「売上高」を開示していないため found=false が返り、代わりに開示している「経常収益」での引き直し方が案内されます）
  4. 「日立製作所のセグメント別の売上収益と利益を、直近 2 期で比べて」（→ 区分は日立が定義した名前のまま、利益は日立が使う物差しのまま返ります）

値の見方

  • value は XBRL に書かれた文字列のままです（金額は円・比率は 0.444 の形。unit・decimals つき）。換算・丸め・補完はしていません。
  • 連結と単体（提出会社）は別の系列です（basis）。平均年間給与・資本金・配当などは単体にだけあります。連結財務諸表を作成していない会社に連結を指定すると found=false です。
  • 「売上高」が無い会社があります（IFRS の会社は「売上収益」、銀行・保険は「経常収益」、鉄道・持株会社は「営業収益」、建設は「完成工事高」、会社が独自に定義した項目 など。全体の約 1 割）。そのとき suggest に、その会社が代わりに開示している項目と引き直し方が返ります。これらは「売上高」とは別の概念なので、返ってきたラベルのまま扱ってください。
  • 同じ決算期の値は後年の書類に再掲され、遡及修正で変わることがあります。既定は提出日が最新の書類の値で、他の書類の値は source.other_documents に並びます（doc_id で書類を指定できます）。
  • IFRS の表と日本基準の表を併記する会社や、会計基準の移行年には、同じ項目に基準ごとの値が並びます。既定は書類が宣言する会計基準の値で、もう一方は other_standards に必ず添えられます。
  • 平均年齢・平均勤続年数を「年」と「月」に分けて開示する会社があります（companion に対の値。40 年と 5 月＝40 歳 5 か月）。
  • セグメント別（lookup_segments）の値は各書類に当期・前期の 2 期だけです。区分の足し算の関係は返しません＝合計を作るときは kind を見て、調整額・全社・合計・会社が定義した小計を二重に数えないでください。セグメント利益が営業利益・経常利益・事業利益のどれかは会社ごとに違います（element と label のまま）。

取得元と利用条件

取得元内容規約区分
EDINET（金融庁）有価証券報告書（「主要な経営指標等の推移」・従業員の状況・セグメント情報）。EDINET API により取得。要素の日本語の呼び名は EDINET の公式 CSV の項目名EDINET 利用規約（公共データ利用規約 第 1.0 版）○（出典の明記と加工の明記）

出典表示の例：「出典：EDINET 有価証券報告書（○○株式会社・2026-06-20 提出・書類管理番号 S100XXXX）／XBRL から抽出」。応答の source.citation にそのまま使える 1 行が入っています。原文（有価証券報告書そのもの）は再配布していません。

収集する情報

ツール名・引数（社名・項目・決算期等）・該当有無・時刻・利用者のメールアドレスのハッシュ値を 30 日間記録し、収録の拡充と品質改善に使います。会話本文は取得しません。詳細はプライバシーポリシー。

制限

  • 収録は有価証券報告書の提出会社 約 4,100 社・直近の書類に載る 5 期分（2026-09 時点）。半期報告書・訂正報告書・決算短信・セグメント別／地域別の内訳・定性情報（事業等のリスク 等）は未収録です。
  • 有価証券報告書を提出していない会社（多くの非上場会社）は収録されていません。
  • レート制限があります（通常の対話利用では到達しません）。
