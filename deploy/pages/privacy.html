プライバシーポリシー

更新日：2026-09-03

岡村 健一（以下「運営者」）は、Polyarchy（stats／recommendations／companies 各サービス。以下「本サービス」）において、次のとおり利用者の情報を取り扱います。

1. 収集する情報

情報内容取得方法
認証情報メールアドレス（および認証プロバイダが発行する利用者識別子）接続時の OAuth 認証（外部認証プロバイダ。現在は WorkOS AuthKit）。本サービスの利用にはログインが必要です。運営者のサーバは検証済みのメールアドレスを受け取り、ハッシュ値（SHA-256 の先頭 16 桁）に変換して保存します。メールアドレスの平文はサーバ側の記録に残しません（メールアドレスが得られない場合は、プロバイダが発行する利用者識別子のハッシュ値で代替します）
利用記録（捕捉ログ）ツール名・ツールに渡された引数（検索語・系列 ID・期間・団体等）・結果件数または該当有無・時刻・利用者ハッシュツールが呼ばれるたびにサーバが記録
接続ログ接続元 IP・時刻・パス・応答コード等の技術情報Cloudflare および運営者のサーバの標準的なアクセスログ

収集しないもの：会話の本文、Claude のメモリ・チャット履歴・要約、利用者がアップロードしたファイル。本サービスのツールはこれらにアクセスしません。ツールの機能に必要な引数以外の会話データは記録しません。

2. 利用目的

  • 認証・アクセス制御（契約者・許可された利用者だけに提供するため）。
  • 利用者数・利用量の把握、料金の算定（将来有償化した場合）。
  • 検索・参照品質の改善：どのような統計・文書が求められ、何が見つからなかったか（found=false）を集計し、収録データの拡充と評価セットの改善に使います。
  • 不正利用の検知・障害対応。

3. 保存期間

  • 利用記録（捕捉ログ）：30 日で自動削除します（サーバ上の削除ジョブとバックアップ先のライフサイクル設定の両方で担保）。集計後の統計（件数等）および評価セットに転記した検索語（利用者を識別できない形）は保持します。
  • 認証セッション：認証プロバイダ（WorkOS AuthKit）の設定に従います。
  • 接続ログ：Cloudflare および運営者のログ設定に従い、通常 30 日以内。

4. 第三者への提供

運営者は、法令に基づく場合を除き、利用者の情報を第三者に販売・提供しません。ただし、本サービスの提供に不可欠な次の事業者が、各社のポリシーに従って情報を処理します。

  • WorkOS, Inc.（認証基盤。ログイン時のメールアドレス等は WorkOS のポリシーに従って処理されます）
  • Cloudflare, Inc.（通信経路・DNS・公開ページの配信）
  • Amazon Web Services（サーバ・バックアップ保存。東京リージョン）
  • Anthropic, PBC（Claude が本サービスへ接続する経路。利用者と Anthropic の間の取り扱いは Anthropic の規約・ポリシーによります）
  • OpenAI（ChatGPT のコネクタから本サービスへ接続する場合の経路。利用者と OpenAI の間の取り扱いは OpenAI の規約・ポリシーによります）

5. 安全管理

  • 通信は TLS で暗号化し、サーバは受信ポートを開けず Cloudflare Tunnel 経由でのみ到達可能にしています。
  • 本サービスのツールは読み取り専用で、公開データのみを扱います。
  • 秘密情報（トンネル資格情報・API キー等）はクラウドのシークレット管理サービス（AWS Systems Manager Parameter Store）に保管し、ソースコードのリポジトリには置きません。

6. 利用者の権利

利用記録の開示・削除、接続の停止を希望される場合は、下記の連絡先までご連絡ください。利用者ハッシュに紐づく記録を削除します。

7. Cookie

本サービスの MCP エンドポイントは Cookie を使用しません。認証画面（WorkOS AuthKit）は認証セッションのために Cookie を使用します。

8. 変更

本ポリシーを変更する場合は本ページに掲示し、更新日を改めます。
