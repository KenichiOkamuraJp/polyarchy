Polyarchy — 政策言説と公的統計の参照サービス（Claude コネクタ）

Polyarchy は、日本の政策言説（経済団体・政府の公表資料）と公的統計を、出典つきで Claude から検索・参照するための リモート MCP サーバ群です。各サービスは読み取り専用で、公開データのみを扱います。文章の生成は利用者ご自身の Claude が行い、 サーバ側では生成 AI を呼びません。

サービス中身ドキュメント
stats（統計参照DB）e-Stat・内閣府・財務省・総務省・日本銀行・社人研・IMF・OECD・世界銀行の統計値を「公表どおりの値」で厳密参照。該当がなければ「ない」と返す/stats
recommendations（政策主張DB）経団連・経済同友会・日本商工会議所・連合・政府（骨太方針・規制改革・財政審）の公表提言を横断検索/recommendations
companies（企業情報DB）有価証券報告書（EDINET・金融庁）の経営指標・従業員の状況を「公表どおりの値」で厳密参照。連結と単体を混ぜず、該当がなければ「ない」と返す/companies

共通の約束

  • 検索・参照専用：メール送信・ファイル書き込み等の外部作用を持つツールはありません（全ツール readOnlyHint）。
  • 公開データのみ：非公開データは構造的に返りません。
  • 出典つき：返す内容には必ず出典（発行体・統計名・表・URL・取得日）が付きます。
  • 保証しない：値・文書の正確性は原典で確認してください（利用規約）。
  • 収集するデータは最小限：会話本文は取得しません（プライバシーポリシー）。

接続のしかた（カスタムコネクタ）

  1. claude.ai → Customize → Connectors → Add custom connector（Team/Enterprise は組織 Owner が Organization settings → Connectors）。
  2. 各サービスのドキュメントに記載の URL を入力 → 「Connect」→ ブラウザで開くログイン画面でサインイン（初回はアカウント登録）。
  3. チャットの「＋」→ Connectors で有効化。

Anthropic のコネクタ・ディレクトリへの掲載は準備中です。
