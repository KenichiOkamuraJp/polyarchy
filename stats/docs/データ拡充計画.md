## 4. 各バッチの設計上の注意（先に決めておくこと）

- **第2弾 規模別の区分**：法人企業統計の資本金階級は年で区分が変わる（cat03 に 16 区分・一部は「H20年度まで」）。最小版は **3 区分（10億円以上／1億〜10億円未満／1千万〜1億円未満）** に絞り、区分定義を notes に刻む。業種は「製造業／非製造業」の2つ（細分は要望次第）。
- **第2弾 四半期**：年度四半期表記 `FY2024Q1`（4-6月）。季節調整値（0003066618）は別系列＝最小版外。
- **第3弾 国際比較の定義差**：IMF の日本の失業率・インフレ率は国内統計と**一致しないことがある**（定義・年平均の取り方）。国内分析は総務省系列、国際比較は IMF/OECD 系列と使い分ける旨を notes と説明文に書く。混ぜて作らない。
- **第3弾 版**：WEO は年2回改定で過去値も動く。最新版のみ保持（②判断5）・`edition` を刻む・予測年は `kind=projection`。
- **第4弾 SNA**：xlsx の生値は二進小数のため**表示書式の桁で文字列化**（esri.py 実装済の規則）。基準改定（次回 2025 年基準）で全系列が別 series になることを前提に dataset に基準年を入れてある。**旧基準（68SNA/93SNA）は別 dataset（sna1990/sna2000）で並列に持ち接続しない**——同じ FY1994 の非金融法人企業 純貸出が 68SNA −2,169.9／93SNA −3,822.7／2008SNA +3,888.6（10億円）と水準が違う。長期の IS バランスは利用側が基準を明示して並べる。
- **第5弾 PDF**：経団連妥結は recommendations 既収 PDF から。表体裁の年差があるので、パーサは「一致しなければエラー」で人手確認へ回す。
- **第5弾 人口**：人口推計は国勢調査基準ごとの e-Stat 表を `parts` で束ねる（公表主体自身が接続した補間補正人口を使う＝こちらで接続しない）。将来推計は中位・低位を dims で分けた別系列（`kind=projection`）。
- **第5弾 日銀フラットファイル**：国際収支・対外資産負債残高の値は未丸めの小数（公表表は億円整数）。値は日銀ファイルの文字列そのまま＝見た目の差は notes に明記。
- **第5弾 取れないもの**：毎勤・有効求人倍率は e-Stat API では現行値が取れない（DB 更新停止／未収録）。短観・為替は日銀サイト直置きが旧ベースのみ＝時系列サイト CGI が要る。
- **第5弾 財政統計**：主要経費別は「見出し行に値があればそれ・無ければ次の『計』行」（小計は飛ばす）。分類は年度で変わるので原典の区分どおり（合計は「合計」行）。単位は表ごと（円／百万円／千円）で換算しない。
- **第5弾 妥結 PDF（2026-08-18 に status=guide へ切替＝値を保持しない・読み方だけ案内。再配布条件.md）**：総平均の位置規則（大手＝[社,円,％]×2 の2回目直後、中小＝「その他非製造業」後の括弧なし数値 [10:14]）。縦書き分割トークンに対応。**各年 PDF の前年欄が前年 PDF と一致することを取込時に検証**（不一致はエラー）。

## 5. 判断が要る点（選択肢と推奨）

1. **順序**：(a) 2→3→4→5（推奨：安い順・PdM 方針の①②を先に）／(b) 3 を先に（国際比較を急ぐ場合）。
2. **第2弾の範囲**：(a) BS 一式＋規模別・業種別・四半期まで一気に（推奨：同一経路で1〜2セッション）／(b) BS 一式だけ先に。
3. **国リスト**：当初は G7＋中韓の 9 か国。**2026-08-18 に OECD 加盟38＋主要非加盟8＝46 か国へ拡張**（国際比較で北欧・アイルランド等が引けないのは実利用で効いた＝ドッグフーディング由来）。OECD 系列は収録国のみ（生産性DB 41＝加盟38＋BGR/HRV/ROU・中国なし／平均賃金 38＝加盟国のみ）。集計値（OECD・EA20・EU27_2020）は ISO3 でないため入れない。一覧外の国は従来どおり found=false。
4. **更新運用の開始時期**：(a) 第2弾完了後に月次バッチを手動で回し始める（推奨）／(b) 配信（箱）と同時。
5. **評価セットの人手確認**：(a) 各バッチで新規分だけ都度確認（推奨）／(b) 溜めて一括。
