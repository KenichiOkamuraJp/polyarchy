# データソース選定 — 候補指標ごとに「完全一致で取れるか」を確定する

> **状態：設計（安定リファレンス・起案時の判断。現行の実装名・数値は stats/README とルート README）。**

版: 2026-08-16（D3 最初の一手②）／入力: `指標棚卸し.md` §5 の S/A 候補（§6 の判断は全て推奨案で確定済み）。
出力: 各系列の **取得元・アクセサ（URL／表番号／API パラメータ）・粒度・完全一致の根拠**、および「取れない」の明記。次＝③`参照粒度設計.md`。

原則
- **原典＝公表主体の一次ファイル／API** から取る。二次資料（他省庁の会議資料・新聞・民間端末）は経由しない。同じ表が複数経路で取れるときは「公表主体の一次経路」を正、e-Stat API を副（機械可読の利便）とし、レジストリには両方を刻む。
- 「完全一致で取れる」＝ 公表値をそのまま（丸め・単位換算・季調・接続をこちらで施さず）保持でき、評価セットで**原典の当該セルと同一の数値**を突き合わせられること。派生値（分配率・GDP比・前年比）は参照層では計算しない（③で「派生系列」の扱いを別に決める）。
- 取得は**取得日・取得元 URL・ファイル/表の版（公表日・基準年）**を必ず刻む（出典契約 §2）。

## 4. 「取れない」と明記するもの（最小版の範囲外）

- 民間出典：Investing.com（金利・為替・株価）→ 公式に置換／東京商工リサーチ 倒産／QuickFactset／IMD 競争力ランキング／MSCI 指数構成。**再配布条件と原典性の両方で採らない**。
- 会議資料の一回限りの図表：社会保障・税の純負担率（国民会議資料）／実質賃金要因分解（年金部会資料）／新しい資本主義会議資料経由の企業財務・開廃業率（→原典 C1〜C4・C9 で採る）。
- 有価証券報告書の企業別セグメント情報（企業別データは本サービスの対象外）。
- 同友会 景気定点観測アンケート（会員意識調査＝主張側。発見層への登録は recommendations の系列参照として可）。
- 内閣府「中長期試算」「長期推計」のケース別将来値：**統計値としては取れない**。projection として社人研推計と同じ器で持つ（③）。
- SNA の基準・体系をまたぐ長期接続系列（F10 のような 1968SNA→2008SNA 接続）：接続はしない（各基準の系列を並べて返す）。
- 政策金利「目標値」（無担保コール O/N 誘導目標）：統計ではなく政策決定値。日銀公表の実勢（月中平均）系列で代替し、目標値は「ない」。

## 5. 依存・秘密・運用

- 秘密：e-Stat appId のみ。SSM `/polyarchy/<env>/estat_app_id`（`共通契約.md` §4）。ローカルは env `ESTAT_APP_ID`（`.env` は git 外・箱に運ばない）。appId が無いときは e-Stat 系列を **found=false ではなく「取得元未設定」のエラー**として区別する（fail-closed だが「ない」と混同しない）。
- 依存：`requests`（既存 env にあり）・`openpyxl`（xlsx）・Shift_JIS デコード（財務省・日銀）。pymupdf は既収 PDF 用。新規の重い依存は足さない。
- キャッシュ：取得ファイル（xlsx/csv/json）は `stats/data/cache/<取得元>/<取得日>/…` に**原本のまま**保存（完全一致テストの根拠＝原本を再現できる）。大物は S3 `data/stats/`。
- 取得の頻度：最小版は**手動バッチ**（起案時の想定名 `stats.ingest.fetch`。現行は `stats/README.md` の実行例を参照）。自動更新は配信後。

## 6. 判断が要る点（選択肢と推奨）

1. **SNA の正＝ESRI 一次 xlsx／副＝e-Stat API** としたが、実装は片方に絞るか：(a) ESRI xlsx のみ（推奨。表構造が固定・基準年がファイル名に出る）／(b) e-Stat API のみ（分類コードで指定できるが SNA の API 収録が部分的）／(c) 両方持ち差分検査。
2. **財務省 予算・国債残高**の取得元：(a) 財政統計 Excel（推奨。決算・当初・補正後が揃う）／(b) 「日本の財政関係資料」の図表元データ／(c) 予算書 PDF 抽出。→ (a) で取れない年は「ない」。
3. **日銀 時系列サイトの取得法**：(a) 系列コード指定の CGI CSV（推奨。セル単位・URL 形式は取込時に固定）／(b) 統計別フラットファイル zip を丸ごと取ってローカルで引く（資金循環は巨大）。
4. **既収 PDF（経団連 妥結）**の抽出：(a) 決定論パーサ＋評価セットで年ごとに人手確認（推奨）／(b) 最小版では発見層登録のみで値は次段。
5. **IMF WEO の版**：(a) 最新版のみ保持（推奨。版名を刻む）／(b) 版ごとに系列を保持（改定履歴の参照が要るなら）。
