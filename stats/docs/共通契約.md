## 2. 約束するもの（入口の作法＝共通契約 §2 を全て適用）

stats 固有の追加：**値を近似で返さない**（換算・丸め・季調・接続なし＝公表どおりの文字列。該当なしは
found=false＋理由）。出典の形＝統計名・調査主体・表番号／API パラメータ・アクセサ・取得日・URL・引用1行＋
`license`（◎/○/△）。`status=guide` の系列は値を持たず原典の読み方だけを返す。

## 3. 名前

- フォルダ名＝コーパスID＝`stats`。Qdrant を使う場合のコレクション接頭辞も `stats_`。
- systemd `polyarchy-stats.service`／公開ホスト名 `stats.<domain>`（現行＝`stats.polyarchy.net`）／MCP サーバ名 `polyarchy-stats`。
- ツール名は用途が読めるもの（`list_datasets`・`find_statistics`・`lookup_statistic`・`lookup_panel`・`list_sources`）。他サービスと衝突しない（利用者 Claude は全コネクタのツールを同じ名前空間で見る）。

## 4. 配信（B 案：別プロセス・別ホスト名）

| 項目 | 値 |
|---|---|
| プロセス | `python -m stats.serving.mcp_server --http --host 127.0.0.1 --port 8766`（cwd・PYTHONPATH＝`/opt/polyarchy/polyarchy`） |
| unit | `deploy/systemd/polyarchy-stats.service`（bootstrap が `ENABLE_STATS_APP=true` のとき設置） |
| 入口 | bootstrap が `ENABLE_STATS_APP=true`＋`TUNNEL_HOST_STATS` のとき cloudflared ingress に `stats.<domain> → http://localhost:8766` を生成。エッジガード（秘密パス 403＋レート制限・**IP 許可は使わない**＝2026-08-28 廃止）は `IP_ALLOWLIST=off ZONE_NAME=<zone> SERVICE=stats MCP_HOST=stats.<domain> SSM_PATH_PARAM=/polyarchy/<env>/stats_http_path bash deploy/scripts/cloudflare-guard.sh apply`（レート制限は Free プラン1本のため `RL_HOSTS=recommendations.…,stats.…` で合算） |
| データ | S3 `data/stats/`（bootstrap が `stats/data/` へ同期）。git 追跡＝`registry/`・`eval/`、git 外＝`values/`・`cache/`・`query_log/`。パスの定義は `stats/core/paths.py`＝箱でも同じ相対構造 |
| コード | tar はリポ全体（`upload_to_s3.sh`）＝stats も同梱。追加作業なし |
| 秘密 | e-Stat appId のみ（**この行が所在の正典**）。取込（ローカル）では env `ESTAT_APP_ID` か `stats/.env`〔git 外〕。serving は e-Stat を呼ばない。箱で使うのは日次の更新チェック（`stats.ops.freshness`）だけ＝任意で SSM `/polyarchy/<env>/estat_app_id` に登録すると bootstrap が `/etc/polyarchy/estat.env` に書く（未登録なら e-Stat 系の更新検知が無効になるだけ）。`.env` は箱に運ばない |
| ゲート | `stats.eval.mcp_smoke`＋`stats.eval.exact_match`＋`stats.eval.test_core`＋`stats.eval.find_quality`（4 本＝ルート README「品質の担保」に基準） |
| **認証（契約値）** | 共通部 §2「認証」のとおり（配線＝`AUTH_AUD_STATS` スイッチ・現行運用はログイン必須）。stats 固有値＝SSM `auth_aud_stats`。healthz・利用者キー・ツール注釈も共通部 §1/§2 が正典（本書には写さない） |
| **公開文書・掲出義務** | `https://docs.polyarchy.net/`（原稿＝`deploy/pages/`・2026-09-02 ドメイン移行済）。**e-Stat API クレジット文**は ① `SERVER_INSTRUCTIONS` と ② `/stats` ページの 2 箇所に掲出（e-Stat API 規約）。`Series.license` を応答に露出。**有償化前の義務**＝IMF 許諾申請・日銀相談（`stats/docs/再配布条件.md`） |
| **配布・検証** | 配布はカスタムコネクタ（URL は個別案内）。検証は staging 本番（`stats.polyarchy.net`・認証付き）か stdio＝**stats-dev／mcp-dev トンネルは廃止（2026-09-02）**。★`cloudflared tunnel run` を Mac で実行しない（箱と同一トンネルの分流事故） |

## 5. 変えないもの（他サービス）

- `recommendations/` のソース・ゲートには触れない。共通契約の変更が必要なら `polyarchy_common` を変え、recommendations 側はゲート4種で不変を確認する（その作業は recommendations のセッションで行う）。
- **データ参照の例外**：一部系列（H5 等）は取得元が recommendations の既収 PDF（`recommendations/data/pdfs/`）＝
  **データファイルの読み取りのみ可**（ソースコードは読まない）。設計＝`stats/docs/データソース選定.md`。
