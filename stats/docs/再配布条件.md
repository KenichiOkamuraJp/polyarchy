# 再配布・商用利用条件の一覧（取得元別）

> **状態：設計（安定リファレンス。取得元の規約の確認結果が変わったら更新）。**

版: 2026-08-18／位置づけ: 公式コネクタ化や、本ソフトウェアを使って有償で提供する場合の前提整理。**各取得元の利用規約を原文で確認**した結果と、stats での対応（出典表示・値の扱い）。
凡例：◎＝出典明示で再配布・商用可（CC BY 4.0 互換）／○＝可だが条件あり／△＝要相談・要確認／原文確認日＝2026-08-18。

前提（全取得元に共通する stats の実装）：
- 値ごとに `source`（機関名・統計名・表・アクセサ・URL・取得日・引用1行）を返す＝**出典明示は機械的に満たす**。
- 値は公表どおりの文字列で**加工しない**（換算・丸め・季調・接続をしない）＝「編集・加工した情報を国が作成したかのように公表しない」条項に抵触しない。派生値は返さない。
- 数値データそのものは著作物ではない（公共データ利用規約 1.0 の明文）。ただし表・文書としての体裁や解説文は著作物＝stats は表の**値だけ**を持ち、文書本文・図表画像は持たない。

## stats 側の対応（実装・運用）

1. **表示（実装済 2026-08-18）**：`Series.license`（grade ◎/○/△・terms・url・note）を全系列に付与（取得経路で決める＝総務省・財務省でも e-Stat 経由なら e-Stat 規約、PDF は経団連）。`lookup_statistic` の `source.license`、`list_datasets` の各 dataset、`find_statistics` の payload に出る。内訳（2026-09-19 実測・10,238 系列）：◎ 9,916（e-Stat 経由・内閣府・財務省・総務省・厚生労働省・社人研・中小企業庁・世銀・OECD・BLS・Eurostat）／○ 11（IMF）／△ 311（日銀 307・経団連 4＝guide・値なし）。
2. **区分の可視化（実装済）**：利用者 Claude は `license.grade` で「この値は商用配布に注意」と判断できる。サーバ説明文と README に e-Stat API クレジット文を載せる（公開時）。
3. **有償化の前**：日銀・IMF に照会し（経団連は guide 化で不要に）、回答を本文書に追記。回答待ちの間は該当 dataset を有償配信から外す（発見層には出す・参照層は個人利用のみ）という段階運用も可能。
4. **e-Stat appId**：利用者には渡さない。所在の正典＝[共通契約.md](共通契約.md)「秘密」の行（取込はローカル・箱では更新チェックだけが任意で使う）。負荷は月次バッチ（短時間の大量アクセス禁止に配慮して系列単位で逐次）。

## status=guide（値を保持せず読み方だけ案内）＝再配布条件への構造的な対応（2026-08-18）

- 条件が厳しい取得元は、値を stats に取り込まず**発見層だけに置く**：`find_statistics`／`list_datasets` には出る（存在・所在・粒度・単位が分かる）が、`lookup_statistic` は `found=false, reason=guide_only` と `guide`（原典 URL・文書名・表・行・列・値の形・注意・代替統計・ライセンス）を返す。**値は利用側 AI が原典を読んで取得**し、stats はその値を保証しない（応答に明記）。
- リンクと読み方の案内は「転載・複製」に当たらないので、経団連・日銀のどちらの規約でも相談不要。有償化しても相談先が減る。
- 適用：経団連 春季妥結 4 系列（2026-08-18）。日銀の系列（2026-09-19 時点 307）は値を保持したまま（無償は出所明記で転載可）＝有償化の判断時に相談か guide 化かを選ぶ。
- 限界：完全一致の保証が利用側に移る／機械アクセスを弾く取得元（IMF・OECD の Web）は指南しても利用側が読めないことがある（経団連 PDF は普通に取れる）。
