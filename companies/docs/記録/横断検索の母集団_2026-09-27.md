# 横断検索の母集団での結果（第 1c 便・4,143 社・2026-09-27）

> **状態：記録（検証結果・2026-09-27。更新しない）。**

[第 1c 便 計画](../第1c便_計画.md) §5 の 3「母集団で洗う」の結果。式エンジン（`core/screen.py`）で、検証済みの型ごとに全社を計算し、除外の理由の内訳を数えた。
基準日 2026-09-27・各社の最新の書類・basis は会社ごとに連結を優先・業種の絞り込みなし。

## 1. 型ごとの計算できた会社と除外の内訳

| 型 | 計算できた | 除外（理由と件数） |
|---|---|---|
| ROA（`roa`） | 4,015 | 5 期推移の外 77・変則決算 45・入力の開示なし 4・会計基準の変更 2 |
| 当期純利益率（`net_margin`） | 4,047 | 入力の開示なし 65・変則決算 29・会計基準の変更 2 |
| 経常利益率（`ordinary_margin`） | 3,752 | 入力の開示なし 346（IFRS・米国基準＝経常利益が無い）・変則決算 29・会計基準の変更 16 |
| ROA の変化（`roa_change`） | 3,939 | 5 期推移の外 137・変則決算 59・入力の開示なし 6・会計基準の変更 2 |
| 売上の前年比（`top_line_growth`） | 3,958 | 5 期推移の外 76・入力の開示なし 64・変則決算 45 |
| 海外売上比率（`overseas_sales_ratio`） | 2,098 | 会社の文で「本邦 90% 超」1,661・表が無く判定できない 247・本邦と合計を特定できない 77・欄が無い 55・表に本邦の区分が無い 5 |
| ROE（開示値・`roe`） | 3,879 | 入力の開示なし 233・変則決算 29・会計基準の変更 2 |

- 「5 期推移の外」＝書類に前期の値が無い会社（新規上場・連結の開始 等）。ROA は期首の総資産に前期末を使うため、当期だけの会社は計算しない。
- 「入力の開示なし」（当期純利益率・売上の前年比の約 65 社）＝最上段の収益を標準の項目で開示していない会社（会社が独自に定義した項目＝ソニー 等）。独自の項目で埋めない。
- 海外売上比率の 2,098 社＝表から比率を計算できた 1,318 社と、会社の文で「本邦以外に売上が無い」＝0 の 780 社の和。
- 変則決算は開示値（ROE）にも当てている（共通の規則 ④）。開示値だけの条件で変則決算を外すかは、実利用で要るとわかってから決める。

## 2. 問い「海外売上比率 90% 以上の非製造業」

非製造業 2,704 社のうち **5 社**（オプティマスグループ 98.3%・ネクソン 97.1%・ガーラ 96.1%・データセクション 94.1%・Abalance 93.1%）。
会社の文で下限を満たさないと確定した会社 1,314・除外 258（表が無く判定できない 181・欄が無い 42・本邦と合計を特定できない 33・表に本邦の区分が無い 2）。

- ガーラの分類の基準は「連結会社の所在地」（多くの会社は顧客の所在地）＝行に注の文を添える。
- ★着手前の粗い実測（計画 §1）で 94.5% と出たアストマックスは、事業ごとの表（ディーリング事業）だけを拾った誤りだった。エンジンは合計のセルがタグの営業収益と一致しないため除外する＝**合計の 2 経路の照合が、表の取り違えを止めた実例**。
- 業種は登録の業種（Abalance は情報・通信業だが売上の大半は子会社の太陽光パネル）＝寄せずに返す。
