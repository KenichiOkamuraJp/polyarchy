### E-C6（極小スペック用の配布変種＝計画・2026-09-18）<a id="e-c6"></a>
- **位置づけ**＝AWS を使わずに 1 台の安価なサーバ（VPS）で建てる道を、公開リポジトリの汎用の手順として持つ（小さな団体・個人が対象）。ホスト名・鍵・ドメインなど環境固有のものは各自のインスタンス側（git 外）。既存の AWS 向け手順（Terraform）は残す。
- **そのまま使えるもの**＝Cloudflare Tunnel（受信ポートを開けない設計は維持）・bootstrap の大半・systemd ユニット・自動適用と自動切り戻し・依存ロック・個人認証（外部 IdP）・ゲート一式。
- **置き換えが要るもの**（deploy 配下の参照ファイル数＝SSM 25・S3 11・CloudWatch 9・SNS 8）：

  | AWS | 役割 | 置き換え |
  |---|---|---|
  | S3 | データ原本・配布マニフェスト・ダッシュボード・ログ退避（30 日削除） | S3 互換のオブジェクトストレージ（`aws s3` はエンドポイント指定で動く＝スクリプトの変更は接続先の引数化が中心） |
  | SSM Parameter Store | 秘密の保管 | 箱の上の権限 600 の env ファイル（serving の秘密は cloudflared の資格情報だけ） |
  | SSM Session Manager | SSH なしで箱に入る | トンネル経由の SSH 等（受信ポートは開けないまま） |
